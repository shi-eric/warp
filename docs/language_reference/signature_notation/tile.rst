.. _builtin-notation-tile:

Tile notation
=============

``Tile[dtype, shape]`` describes a tile with the given element type and shape.
``tuple[int, ...]`` in the shape slot leaves the number of dimensions and their extents open.
See :doc:`Tiles </user_guide/programming_model/tiles>` for tile operations and examples.

See :ref:`reading-built-in-signatures` for examples of how overloads use this notation.
