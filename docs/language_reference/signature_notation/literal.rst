Literal notation
================

``Literal[value]`` specifies a fixed value in a type annotation.
For example, ``Vector[Scalar, Literal[3]]`` specifies a three-component vector.
See `typing.Literal in the Python documentation <https://docs.python.org/3/library/typing.html#typing.Literal>`_.

See :ref:`reading-built-in-signatures` for examples of how overloads use this notation.
